# Introduction

Zephyr Sensor Anomalies is a [Zephyr RTOS](https://www.zephyrproject.org/) library that allows to track anomalies in a provided set of sensors using machine learning models running on [Kenning Zephyr Runtime](https://github.com/antmicro/kenning-zephyr-runtime) or [emlearn](https://github.com/emlearn/emlearn).
It provides tools for:
* [Reading data from sensors](reading-sensor-data) and using it to generate datasets,
* [Real-time anomaly detection](real-time-detection) using trained neural networks.
